# Support

- Use GitHub Discussions Q&A for setup questions and usage help.
- Use GitHub Discussions Ideas for product suggestions; mature, actionable
  proposals may be converted into GitHub Issues.
- Use a GitHub issue for reproducible defects and scoped implementation work.
- Use GitHub private vulnerability reporting for security concerns.
- The community Discord linked from the product site is suitable for informal
  conversation but is not the system of record for defects or security reports.

Include the Raid Signal version, Windows version, relevant non-sensitive error
text, and reproduction steps. Never post invitation links, encryption keys,
private server addresses, or logs containing personal paths.
