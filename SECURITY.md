# Security policy

## Supported versions

Only the latest GitHub Release receives security fixes.

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** private reporting
form. Do not open a public issue for suspected vulnerabilities and do not include
invitation URLs, keys, private server addresses, logs, or personal data in public
threads.

Include affected version, impact, reproduction steps, and a minimal proof of
concept. You should receive an acknowledgement within seven days. Please allow a
reasonable remediation window before public disclosure.

Never test against infrastructure or users you do not own or have explicit
permission to assess. Safe research against your own local relay is welcome.
